# Математическое обоснование научной новизны: связка бустинг-классификации и условной ГАН

## 1. Постановка задачи

Пусть дано множество биометрических признаков пользователя  
$$X = \{x_1, x_2, \dots, x_d\} \subset \mathbb{R}^d,$$  
где $d=4$ (ЧСС, HRV, SpO2, температура тела) в базовой конфигурации, и может расширяться до дополнительных признаков (артериальное давление, продолжительность сна, энергозатраты).

Необходимо построить функцию классификации функционального состояния  
$$F: \mathbb{R}^d \to \{0, 1, \dots, C-1\},$$  
где $C=7$ — число классов: восстановление, базовая выносливость, пороговая выносливость, силовая нагрузка/HIIT, перетренированность, заболевание, неопределённое состояние.

Далее, для сгенерированного класса состояния $c = F(x)$ необходимо построить персонализированный план тренировки  
$$P \subset \mathbb{R}^P,$$  
где $P=19$ — размерность вектора параметров плана (упражнения, продолжительность, интенсивность, интервалы отдыха и т.д.).

## 2. Компонент 1: Бустинг-классификатор

Используется градиентный бустинг на гистограммах (`HistGradientBoostingClassifier` из `scikit-learn`). Модель обучается на датасете  
$$\mathcal{D}_{train} = \{(x^{(i)}, y^{(i)})\}_{i=1}^N, \quad x^{(i)} \in \mathbb{R}^d, \; y^{(i)} \in \{0,\dots,C-1\}.$$

Предикт модели имеет вид ансамбля ансамблей деревьев принятия решений:  
$$F(x) = \underset{c \in \{0,\dots,C-1\}}{\arg\max} \sum_{m=1}^M \eta \cdot h_m(x, c),$$  
где $h_m$ — $m$-ое дерево, $\eta$ — темп обучения (learning rate), $M$ — число итераций.

Экспорт модели производится в виде матрицы весов $W \in \mathbb{R}^{C \times d'}$ (линейная аппроксимация бустинга для инференса на Go), где $d'=4$ — число признаков, используемых в быстрой инференции.

Предсказание на стороне Go (линейный классификатор из экспортированных весов):  
$$\text{score}_c(x) = \sum_{j=1}^{d'} W_{c,j} \cdot x_j, \quad c \in \{0,\dots,C-1\},$$  
$$F_{go}(x) = \underset{c}{\arg\max} \; \text{score}_c(x), \quad \text{confidence}(x) = \sigma(\max_c \text{score}_c(x)),$$  
где $\sigma(z) = \frac{1}{1+e^{-z}}$ — сигмоида.

## 3. Компонент 2: Условная ГАН для генерации планов

После определения состояния $c = F(x)$ применяется условная générativная состязательная сеть (Conditional GAN) для генерации персонализированного плана тренировки.

### Генератор

$$G: \mathbb{R}^L \times \mathbb{R}^{C+5} \to \mathbb{R}^P,$$  
где $L=100$ — размерность latent-вектора $z \sim \mathcal{N}(0, I_L)$, $C+5$ — размерность условия (one_hot кодировка класса состояния + 5 демографических признаков пользователя: возраст, пол, вес, рост, цель), $P=19$ — размерность плана.

Генератор представляет собой multilayer perceptron:  
$$G(z, c) = f_{W_g}([z \; \| \; c]),$$  
где $\|$ — конкатенация векторов, $f_{W_g}$ — глубокая сеть с активациями LeakyReLU и BatchNorm, выходной слой с активацией $\tanh$ для вывода в диапазоне $[-1, 1]$ с последующей денормализацией.

### Дискриминатор

$$D: \mathbb{R}^P \times \mathbb{R}^{C+5} \to [0, 1],$$  
$$D(p, c) = f_{W_d}([p \; \| \; c]),$$  
где $f_{W_d}$ — сеть с LeakyReLU и Dropout, выходной слой с сигмоидой для оценки вероятности того, что план $p$ реален при условии $c$.

### Функции потерь

Дискриминатор обучается на максимизацию:  
$$\mathcal{L}_D = -\mathbb{E}_{(p,c)\sim p_{data}}[\log D(p,c)] - \mathbb{E}_{z\sim p(z), c\sim p(c)}[\log(1 - D(G(z,c), c))].$$

Генератор обучается на минимизацию:  
$$\mathcal{L}_G = -\mathbb{E}_{z\sim p(z), c\sim p(c)}[\log D(G(z,c), c)].$$

Игровая цель (minimax):  
$$\min_G \max_D V(D,G) = \mathbb{E}_{(p,c)\sim p_{data}}[\log D(p,c)] + \mathbb{E}_{z\sim p(z), c\sim p(c)}[\log(1 - D(G(z,c), c))].$$

## 4. Связка бустинга и ГАН

Ключевая научная новизна заключается в **классификации-кондиционированной генерации**: вывод бустинга (класс состояния) используется как условие для ГАН, что позволяет генерировать планы, адекватные текущему функциональному состоянию пользователя.

### Конвейер (pipeline)

$$
\underbrace{x \in \mathbb{R}^d}_{\text{биометрия}}
\xrightarrow{F}
\underbrace{c \in \{0,\dots,C-1\}}_{\text{класс состояния}}
\xrightarrow{\text{one\_hot}}
\underbrace{c_{oh} \in \{0,1\}^C}_{\text{условие для ГАН}}
\xrightarrow{G(z, [c_{oh} \parallel u])}
\underbrace{p \in \mathbb{R}^P}_{\text{персонализированный план}},
$$  
где $u \in \mathbb{R}^5$ — пользовательские признаки, $z \sim \mathcal{N}(0, I_L)$ — шум генератора.

### Математическое обоснование новизны

**Теорема 1 (существование оптимального условия).**  
Пусть распределение реальных планов при условии класса $c$ задаётся как $p(p|c)$. Тогда оптимальный дискриминатор при фиксированном генераторе:  
$$D^*(p,c) = \frac{p(p|c)}{p(p|c) + p_g(p|c)},$$  
где $p_g(p|c)$ — распределение сгенерированных планов. При оптимальном генераторе $p_g(p|c) = p(p|c)$, и $D^*(p,c) = \frac{1}{2}$.

**Теорема 2 (связь с бустингом).**  
Класс $c$, полученный от бустинга, является достаточной статистикой для выбора условия генерации, так как бустинг максимизирует разделимость классов в пространстве биометрических признаков:  
$$I(X; C) \to \max,$$  
где $I(\cdot;\cdot)$ — взаимная информация. Это гарантирует, что условие $c$ несет максимально возможную информацию о функциональном состоянии пользователя для последующей генерации плана.

## 5. Персональная дельта (локальная адаптация)

Для компенсации недообученности базовой модели на ранних этапах вводится персональная векторная дельта $\Delta_u \in \mathbb{R}^{C \times d'}$, хранимая локально на устройстве пользователя.

Инференс с дельтой:  
$$\text{score}_c(x, \Delta_u) = \sum_{j=1}^{d'} (W_{c,j} + \Delta_{u,c,j}) \cdot x_j.$$

Обновление дельты при обратной связи пользователя (оценка $t \in \{0, 1\}$, где 1 — план принят, 0 — отклонён):  
$$\Delta_{u,c,j} \leftarrow \Delta_{u,c,j} + \eta \cdot (t - \hat{y}_c) \cdot x_j,$$  
где $\hat{y}_c = \sigma(\text{score}_c(x))$ — текущая вероятность класса, $\eta$ — скорость обучения.

Это позволяет адаптировать модель под конкретного пользователя без переобучения всей сети и без передачи персональных данных на сервер.

## 6. Итоговая архитектура

```text
Биометрия X → [Бустинг F] → Класс c → [Условие c_oh || u] → [Генератор G] → Персональный план P
                                                        ↑
                                                    Шум z ~ N(0, I)
                                                        ↑
                                            Персональная дельта Δ_u (локально)
```

**Научная новизна:**  

1. Сочетание бустинг-классификации функционального состояния с условной ГАН для генерации персонализированных планов нагрузки — первый в данной предметной области подход "классификация → генерация" вместо традиционного "классификация → выбор из шаблонов".  
2. Локальная персональная дельта Δ_u позволяет адаптировать модель под пользователя без серверных ресурсов и без нарушения конфиденциальности (152-ФЗ).  
3. Полностью локальная инференсная цепочка (бустинг + ГАН на ПК пользователя) исключает зависимость от внешних API и сторонних сервисов.
