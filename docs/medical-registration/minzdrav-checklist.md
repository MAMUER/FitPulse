# Чеклист для регистрации медицинского ПО в Росздравнадзоре

## 1. Подготовительный этап

### 1.1 Юридическая экспертиза

- [ ] Анализ функционала FitPulse на соответствие определению медицинского ПО
- [ ] Определение границ wellness vs medical
- [ ] Оценка требований к сертификации
- [ ] Выбор схемы сертификации (добровольная / обязательная)

### 1.2 Техническая документация

- [ ] Описание архитектуры системы
- [ ] Описание алгоритмов ML (генерация планов, классификация состояния)
- [ ] Описание обработки персональных данных
- [ ] Описание мер безопасности
- [ ] Описание интеграций с внешними сервисами

### 1.3 Организационные меры

- [ ] Назначение ответственного за сертификацию
- [ ] Подготовка договора с аккредитованной организацией (если требуется)
- [ ] Подготовка внутренних регламентов

## 2. Подача заявки

### 2.1 Документы для Росздравнадзора

1. **Заявка** на сертификацию
2. **Техническая документация**
3. **Документы о conformity** (если есть)
4. **Договор** с аккредитованной организацией (при необходимости)
5. **Выписка** из ЕГРЮЛ/ЕГРИП
6. **Доверенность** на представителя

### 2.2 Процедура

1. Подача заявки через [ГИР portal](https://roszdravnadzor.gov.ru/)
2. Предоставление пакета документов
3. Оплата госпошлины (при необходимости)
4. Прохождение экспертизы
