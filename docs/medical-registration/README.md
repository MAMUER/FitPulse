# FitPulse — Medical Registration Roadmap

## 1. Legal Analysis

### 1.1 Определение медицинского ПО в РФ

Согласно [ФЗ № 152 «О персональных данных»](https://www.consultant.ru/document/cons_doc_LAW_61801/) и [Приказу Минздрава № 334н](https://www.consultant.ru/document/cons_doc_LAW_328950/):

**Медицинское ПО** — программное обеспечение, предназначенное для:
- сбора, обработки, хранения медицинских данных
- поддержки принятия врачебных решений
- диагностики, лечения, реабилитации
- ведения медицинской документации в электронном виде

### 1.2 FitPulse classification

| Критерий | FitPulse | Медицинское ПО? |
| --- | --- | --- |
| Обработка биометрических данных | ✅ Да (пульс, SpO2, вес, состав тела) | Частично |
| Генерация планов на основе физиологического состояния | ✅ Да (ML-классификатор) | Да |
| Интеграция с медицинскими сервисами | 🔄 В roadmap | Да |
| Диагностика заболеваний | ❌ Нет | Нет |
| Назначение лекарств | ❌ Нет | Нет |
| Врачебное сопровождение | ❌ Нет | Нет |

**Вывод**: FitPulse на текущем этапе — **wellness-платформа**, а не медицинское ПО. Однако при добавлении интеграции с медицинскими сервисами и генерации планов на основе медицинских показателей требуется **юридическая экспертиза**.

## 2. Registration Process

### 2.1 Необходимые шаги

1. **Юридическая экспертиза** (1–2 недели)
   - Анализ функционала FitPulse на соответствие определению медицинского ПО
   - Оценка требований к сертификации

2. **Подготовка технической документации** (2–3 недели)
   - Описание архитектуры
   - Описание обработки медицинских данных
   - Описание алгоритмов ML

3. **Подача заявки в Росздравнадзор** (2–4 недели)
   - Форма заявки
   - Техническая документация
   - Доказательство соответствия требованиям

4. **Сертификация** (3–6 месяцев)
   - Тестирование функционала
   - Аудит безопасности
   - Получение сертификата
