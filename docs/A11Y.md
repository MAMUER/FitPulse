# Accessibility (a11y)

FitPulse v11 targets **WCAG 2.1 AA** compliance with selected **WCAG 2.2 AAA** enhancements.

## Implemented measures

### Perceivable

- **Text alternatives:** Icon-only buttons use Font Awesome with meaningful `aria-label` where needed. Decorative icons are marked `aria-hidden="true"`.
- **Color contrast:** Normal theme meets AA for body text. High-contrast mode (`data-highcontrast="on"`) enforces stronger contrast.
- **Resize text:** Layout uses relative units and flexible grids.

### Operable

- **Keyboard accessible:** All interactive elements are focusable. `:focus-visible` outline is forced with `outline: 3px solid var(--blue)`.
- **No keyboard trap:** Tab bar and modals allow escape/return focus.
- **Pause controls:** Stories viewer supports pause via hold. `prefers-reduced-motion` disables animations.
- **Touch targets:** Buttons and tabs have adequate hit areas for mobile.

### Understandable

- **Labels:** Form fields have explicit labels.
- **Error identification:** Validation feedback is shown inline via toast/state updates.
- **Consistent navigation:** Bottom tab bar is persistent across main screens.
- **Language:** `document.documentElement.lang` is updated on language toggle.

### Robust

- **Semantic markup:** Sections use semantic elements where appropriate.
- **ARIA live regions:** Dynamic updates (toasts, metrics) are announced via implicit text changes.

## High contrast mode

Toggle available on login, register, and profile screens. Implemented via `data-highcontrast="on"` attribute on `<html>`. Overrides CSS variables for:

- Backgrounds: white
- Text: black
- Borders: high-contrast colors
- Status badges: explicit high-contrast fills

## Reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
  }
}
```

## Focus management

- Global `:focus-visible` rule: `outline: 3px solid var(--blue); outline-offset: 3px;`
- Buttons and links suppress `-webkit-tap-highlight-color`.
- Disabled buttons use `cursor: not-allowed` and reduced opacity.

## Testing

- Automated: Vitest + React Testing Library for semantics and ARIA attributes.
- Manual: Playwright E2E runs across 8 configurations (RU/EN × Light/Dark × Normal/High Contrast).
- Recommended screen readers: NVDA, VoiceOver, TalkBack.

## Known limitations

- `prompt()`/`confirm()` dialogs are used for simple demo flows (edit place, delete account). In production, replace with accessible modal dialogs (`role="dialog"`, `aria-modal="true"`, focus trap).
- Chart.js canvas fallback is not present in v11 screens; metric modals use text representations instead.

## Cookie consent banner

- Banner имеет `role="dialog"` и `aria-label="Cookie consent"`.
- Кнопки «Принять» и «Отклонить» имеют `aria-describedby` с текстом согласия.
- Фокус перемещается на banner при появлении; после выбора фокус возвращается на страницу.
- Баннер не блокирует прокрутку; позиционируется как `position: fixed` внизу экрана.

## Medical disclaimer

- Визуальный disclaimer имеет `role="note"` и `aria-live="polite"`.
- Текст disclaimer доступен через screen reader при фокусе на форме.
- High-contrast mode применяет контрастные цвета для медицинского предупреждения.
- Disclaimer не исчезает автоматически; пользователь должен явно подтвердить действие.

## Touch targets

- Минимальный размер touch target: **44×44 CSS pixels** (WCAG 2.5.5 Level AAA).
- Кнопки в нижней навигации: высота не менее 48px.
- Кнопки cookie consent: минимальная ширина 64px, высота 44px.
-间距 между touch targets: не менее 8px.

## Color-blind accessibility

- Состояния не используют только цвет для передачи информации; добавляются иконки или текст.
- Примеры:
  - Error: красный цвет + иконка `fa-circle-exclamation` + текст «Ошибка»
  - Success: зелёный цвет + иконка `fa-check` + текст «Успешно»
  - Warning: жёлтый цвет + иконка `fa-triangle-exclamation` + текст «Внимание»
- Все графики и метрики имеют текстовые альтернативы.

## Skip navigation

- На всех страницах присутствует skip link: `<a href="#main-content" class="skip-link">Перейти к основному содержанию</a>`.
- Skip link виден при фокусе (`:focus-visible`), скрыт в остальное время.
- Основное содержимое помечено `id="main-content"`.

## ARIA live regions

- **Toasts**: `role="status"`, `aria-live="polite"`, `aria-atomic="true"`.
- **Metric updates**: `role="status"`, `aria-live="polite"`, `aria-atomic="true"` для изменений в реальном времени.
- **Loading states**: `role="progressbar"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`.
- **Error messages**: `role="alert"`, `aria-live="assertive"` для критических ошибок.

## Dynamic content

- Все обновления в реальном времени (метрики, статусы) анонсируются через `aria-live` регионы.
- Тосты имеют `role="status"` и автоматически скрываются через 5 секунд; screen reader успевает прочитать сообщение.
- Изменения в метриках (пульс, SpO2) анонсируются только при значительном изменении (>10%).
