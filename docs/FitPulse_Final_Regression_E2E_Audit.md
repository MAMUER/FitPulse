## Методика и ограничение

Тест выполнен в Chromium headless на актуальном `/mnt/data/FitPulse_final_v10.html`.
Для изоляции теста HTML загружался через CDP `Page.setDocumentContent`, затем фактический application script выполнялся в браузере.
В тестовой среде прямой переход к `file://` блокируется политикой окружения, поэтому это не физический Android/device E2E.
Native `alert/confirm/prompt` в тестовом harness заменены безопасными test doubles, чтобы клики по соответствующим UI-элементам не блокировали браузер; сами обработчики при этом реально вызываются.
Внешние CDN/изображения не считаются JavaScript errors; отдельная проблема внешних ресурсов ранее была зафиксирована и компенсируется fallback-иконками.
