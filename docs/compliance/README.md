# Документы по compliance

В этом каталоге хранятся документы по обработке персональных данных и compliance на русском языке.

## Названия файлов

Некоторые файлы имеют кириллические имена в соответствии с требованиями к юридической документации:

- `ПОЛИТИКА_ОБРАБОТКИ_ПДН.md` — Политика обработки персональных данных
- `РЕЕСТР_ОБРАБОТКИ_ПДН.md` — Реестр обработки персональных данных
- `ИНСТРУКЦИЯ_ПО_ИНЦИДЕНТАМ.md` — Инструкция по обработке инцидентов
- `ШАБЛОН_ОТЧЁТА_RECOVERY_DRILL.md` — Шаблон отчёта по учениям по восстановлению
- `DPIA.md` — Оценка влияния на защиту данных
- `DPA_YANDEX_ID.md` — Соглашение об обработке данных с Yandex ID
- `SLO_MONTHLY_REPORT_TEMPLATE.md` — Шаблон месячного отчёта по SLO

## Примечание для пользователей Windows

Кириллические имена файлов сохранены для соответствия оригинальной юридической документации.
При возникновении проблем с кодировкой убедитесь, что ваш редактор и терминал используют UTF-8.
