# Data Processing Agreement (DPA) — Yandex ID

> **Назначение:** Настоящий DPA регулирует обработку персональных данных (ПДн) в рамках интеграции FitPulse с Yandex ID. Документ составлен в соответствии с требованиями GDPR (ст. 28) и 152-ФЗ, учитывает трансграничную передачу ПДн и обязанности сторон как контроллера и процессора.

**Ведёт:** Ответственный за обработку ПДн (`mihnikolaenko12@yandex.ru`)  
**Статус:** Активен

---

## 1. Стороны

| Роль | Название | Контакт |
| --- | --- | --- |
| **Контроллер** | FitPulse (Оператор ПДн) | `mihnikolaenko12@yandex.ru` |
| **Процессор** | Yandex LLC (Yandex ID) | `yandex.ru/legal/confidential` |

---

## 2. Предмет обработки

FitPulse использует Yandex ID для аутентификации пользователей. В рамках интеграции Yandex предоставляет FitPulse следующие ПДн из userinfo endpoint:

| Категория ПДн | Пример | Специальная категория? |
| --- | --- | --- |
| Yandex ID (`id`) | Уникальный идентификатор пользователя Yandex | Нет |
| Email | Адрес электронной почты пользователя | Нет |
| Имя | Имя пользователя из профиля Yandex | Нет |
| Фамилия | Фамилия пользователя из профиля Yandex | Нет |
| Login | Логин пользователя Yandex | Нет |

**Важно:** FitPulse не запрашивает и не получает доступ к другим данным Yandex. Scopes: `login:info`, `login:email`.

---

## 3. Правовое основание обработки

- **GDPR:** Согласие субъекта (Art. 6(1)(a) + Art. 9(2)(a) для специальных категорий, если применимо).
- **152-ФЗ:** Согласие субъекта на обработку ПДн (ст. 9).
- **Yandex Terms of Service:** Политика конфиденциальности Yandex (`https://yandex.ru/legal/confidential`).

---

## 4. Обязанности контроллера (FitPulse)

1. **Минимизация данных:** FitPulse получает только те данные, которые необходимы для аутентификации (`id`, `email`, `login`, `first_name`, `last_name`). Дополнительные scopes не запрашиваются.
2. **Информирование субъекта:** Пользователь информируется о том, что при использовании Yandex ID его email, имя и фамилия передаются в Yandex и обратно в FitPulse. Информация содержится в Политике конфиденциальности (`/privacy`).
3. **Согласие:** Пользователь явно соглашается на обработку ПДн через Yandex ID, принимая Политику конфиденциальности при регистрации.
4. **Защита данных:** Полученные ПДн шифруются в БД через pgsodium (aegis256) и защищаются TLS 1.3 in transit.
5. **Права субъектов:** FitPulse обеспечивает реализацию прав субъектов (доступ, исправление, удаление, портируемость) через API endpoints.
6. **Transparency:** FitPulse информирует пользователя о трансгранильной передаче ПДн (см. раздел 7).

---

## 5. Обязанности процессора (Yandex)

1. **Обработка только по инструкциям:** Yandex обрабатывает ПДн пользователей только в соответствии с инструкциями FitPulse и своими условиями использования.
2. **Конфиденциальность:** Yandex обеспечивает конфиденциальность ПДн пользователей в рамках своей политики конфиденциальности.
3. **Безопасность:** Yandex применяет соответствующие технические и организационные меры для защиты ПДн.
4. **Подпроцессоры:** Yandex может привлекать подпроцессоров в рамках своей обычной деятельности с уведомлением FitPulse.
5. **Удаление данных:** Yandex удаляет ПДн пользователей по их запросу или по запросу FitPulse в соответствии со своими политиками.

---

## 6. Меры безопасности

| Мера | Описание |
| --- | --- |
| Шифрование in transit | TLS 1.3 для всех вызовов Yandex ID endpoints |
| Шифрование at rest | pgsodium (aegis256) для ПДн в PostgreSQL |
| Минимизация данных | Запрашиваются только необходимые scopes: `login:info`, `login:email` |
| Аудит | Все операции с ПДн логируются в audit log |
| Доступ | RBAC для доступа к ПДн |

---

## 7. Трансграничная передача ПДн

При использовании Yandex ID ПДн пользователя (email, имя, фамилия) передаются через серверы Yandex LLC. Yandex обрабатывает ПДн в соответствии с применимым законодательством о защите данных.

---

## 8. Срок действия и прекращение

1. Настоящий DPA действует с момента утверждения и до момента прекращения использования Yandex ID FitPulse.
2. При прекращении использования Yandex ID FitPulse удаляет все ПДн, полученные через Yandex ID, в течение 30 дней.
3. FitPulse уведомляет Yandex о прекращении использования сервиса.
